# Genre Folder Template

Each genre folder should contain:

- `first.md` (you write this; input essay markdown with album tables)
- `spotify_albums.json` (generated by `fetch_spotify.py`)
- `albums_catalog.json` (generated by `fetch_spotify.py`)
- `index.html` (generated by `fetch_spotify.py`; default V3 listening guide)

Generate outputs with:

```bash
python fetch_spotify.py <genre-slug>
```

V3 is always the default. It includes the single click-to-load player, listening cues,
energy/texture map, era ephemera, connections, crate digging, and session notes.

You do not need to manually create JSON files. For later visual-only regeneration:

```bash
python fetch_spotify.py <genre-slug> --reuse-catalog
```
