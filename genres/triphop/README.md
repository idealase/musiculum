# Genre Folder Template

Each genre folder should contain:

- `first.md` (you write this; input essay markdown with album tables)
- `spotify_albums.json` (generated by `fetch_spotify.py`)
- `albums_catalog.json` (generated by `fetch_spotify.py`)
- `index.html` (generated by `fetch_spotify.py`; final HTML report)

Generate outputs with:

```bash
python fetch_spotify.py <genre-slug>
```

You do not need to manually create JSON files.
